# Skydesk

Mock theory exams for flight schools, with automatic SACAA CA 61-184 generation.

**Live:** https://skydesk.linkzoneglobal.com

## Features
- Multi-school accounts: platform super-admin, school admins, instructors, students
- Timed mock exams per SACAA subject from school question banks, auto-marked
- On pass: certificate + CA 61-184 (Proof of Theoretical Knowledge Instruction) PDF filled from the student's profile, signed by the instructor and emailed
- Instructor digital signatures stored privately; downloads use signed links

## Tech
React, serverless backend functions, row-level security, role-based access control, PDF generation, transactional email
